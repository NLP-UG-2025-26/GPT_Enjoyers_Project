# GPT_Enjoyers_Project
# Project Overview
The aim of this project is to develop a web application that combines flight schedule information with real-time aviation weather data. The application will be built using HTML, CSS, and JavaScript. It will integrate a Flight Schedules API (https://airlabs.co) and the weather information available through Aviation Weather Impact Board (https://aviationweather.gov/impactboard). 

The main purpose of the app is to help people better prepare for their flights by providing information about weather conditions at their departure and destination airports. It will allow users to search for a specific flight by its flight number or for an airport using its ICAO code, as well as retrieve current weather observations for the selected airport.
